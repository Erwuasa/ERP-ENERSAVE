    2. public.handle_fase_change() — BEFORE UPDATE on prospectos:
       - When NEW.fase IS DISTINCT FROM OLD.fase: set NEW.fase_changed_at = now() UTC, NEW.dias_en_fase = 0
       - INSERT actividades_ventas (prospecto_id, comercial_id, comercial_name, tipo='cambio_fase', titulo, descripcion, metadata with fase_anterior/fase_nueva)

    3. public.handle_dias_en_fase() — BEFORE INSERT OR UPDATE on prospectos:
       - Set dias_en_fase = floor(extract(epoch from (now() - fase_changed_at)) / 86400)

       - trigger_prospectos_updated_at → handle_updated_at
       - trigger_prospectos_fase_change → handle_fase_change
       - trigger_prospectos_dias_en_fase → handle_dias_en_fase

    Do NOT create client-side cambio_fase insert logic — trigger owns timeline entries per locked decision.
